#  Nutri-Log – Daily Nutrition Calculator

## 📌 Project Overview

**NutriLog – Daily Nutrition Calculator** is a Java-based console application designed to help users track their daily nutritional intake. The system allows users to enter different food items such as milkshakes, smoothies, protein foods, fruits, and healthy fats, and automatically calculates the **total calories, protein, carbohydrates, and fats** consumed.

The project simulates a simple **fitness nutrition tracker**, similar to basic functionality found in real fitness apps.

---

## 🚀 Features

* Database of **50 gym-related food items**
* Calculates **total calories, protein, carbs, and fats**
* Supports different categories such as:

  * Milkshakes
  * Smoothies
  * Protein bars
  * High-protein foods
  * Carbohydrates
  * Healthy fats
  * Fruits
* Interactive **console-based input system**
* Uses **HashMap for efficient food lookup**
* Demonstrates **Object-Oriented Programming (OOP)**

## ⚙️ How the Program Works

1. The program loads a **food database of 50 items** with their nutritional values.
2. The user enters food items one by one.
3. The program searches the food in the database.
4. If the food exists, it adds the nutritional values to the total.
5. When the user types **exit**, the program displays the final nutrition summary.
